# Contributing

Thanks for wanting to help.

- **Found a bug?** Open an issue with the bug form. Your Windows version and a screenshot help most.
- **Have an idea?** Open an issue with the idea form before writing code, so we can agree it fits.
- **New recognition rule?** Rules are JSON files in `src/DiskMap.Core/Rules/data`. A new rule must say exactly what it removes and what happens afterwards, and it must be something that is safe or rebuildable. Rules that delete files people could need won't be accepted.
- **Pull requests:** keep them small and focused, and run the tests first (see "Build from source" in the README).

Please read the [code of conduct](CODE_OF_CONDUCT.md) before taking part.
